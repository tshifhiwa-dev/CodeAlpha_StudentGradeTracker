# Student Grade Tracker

A simple Java application for managing student grades.

## What It Does

- Add students
- Add multiple grades
- Calculate the average grade
- Find the highest and lowest grade
- Show student performance
- View student reports
- View all students

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList

## How to Run

1. Download or clone this repository.
2. Open the project in a Java IDE such as Eclipse, IntelliJ IDEA, or VS Code.
3. Run `Main.java`.
4. Follow the instructions shown in the console.

## Project Files

- `Main.java` – Runs the application
- `Student.java` – Stores student information and grades
- `GradeManager.java` – Manages students and calculates grades
